Flow\n```\nUser drags handle ⋮⋮\n    ↓\nonBlockDragStart() → Add .dragging class\n    ↓\nUser hovers over block\n    ↓\nonBlockDragOver() → Add .drag-over class\n    ↓\nUser drops on block\n    ↓\nonBlockDrop() → Swap blocks in array\n    ↓\nrenderBlocks() → Update DOM\n    ↓\nmarkUnsaved() → Trigger auto-save\n```\n\n### Resize Flow\n```\nUser clicks resize handle ▔▔\n    ↓\nstartBlockResize() → Capture initial state\n    ↓\nUser moves mouse\n    ↓\ndoBlockResize() → Update size in real-time\n    ↓\nUser releases mouse\n    ↓\nstopBlockResize() → Save size, cleanup\n    ↓\nmarkUnsaved() → Trigger auto-save\n```\n\n---\n\n## Integration\n\n### With Existing Features\n- ✅ Auto-save system (uses `markUnsaved()`)\n- ✅ Block rendering (works with all types)\n- ✅ won't drag\"\n**Solution**: Make sure you're clicking the drag handle ⋮⋮, not the content\n\n### \"Size reset on reload\"\n**Solution**: Make sure auto-save completed before reloading (wait 5 seconds)\n\n### \"Drag/resize feels laggy\"\n**Solution**: Check browser's performance (F12 → Performance tab)\n\n### \"Changes not saving\"\n**Solution**: Check:\n1. Auto-save is enabled (isDirty flag)\n2. Server connection working\n3. User has permission to save\n4. No console errors (F12)\n\n---\n\n## Customization\n\n### Minimum Size Constraints\nEdit lines 2608-2609 in block_editor.html:\n```javascript\nconst newWidth = Math.max(200, startWidth + deltaX);  // Change 200 to desired min\nconst newHeight = Math.max(80, startHeight + deltaY);  // Change 80 to desired min\n```\n\n### Drag/Drop Colors\nEdit CSS styles around line 823 in block_editor.html:\n```css\n.ed-block.dragging {\n  border: 2px dashed rgba(139, 120, 204, 0.5);  /* Change color */\n}\n```\n\n### Resize Handle Style\nEdit CSS styles around line 839 in block_editor.html:\n```css\n.ed-block-resize {\n  background: linear-gradient(135deg, transparent 50%, var(--ed-accent) 50%);\n  /* Change gradient/colors */\n}\n```\n\n---\n\n## Known Limitations\n\n### v1.0\n- ❌ No mobile/touch support (coming v1.1)\n- ❌ No keyboard shortcuts (coming v1.1)\n- ❌ No undo/redo (coming v2.0)\n- ❌ No block locking (coming v2.0)\n- ❌ No grid snapping (coming v2.0)\n- ❌ No multi-select (coming v2.0)\n\n---\n\n## Deployment\n\n### Pre-Deployment\n1.
